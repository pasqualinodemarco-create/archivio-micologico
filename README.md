# Archivio Micologico

Plugin WordPress per la gestione e consultazione di un archivio micologico con schede scientifiche, tassonomie gerarchiche, ricerca avanzata e gestione dal frontend.

**Versione:** 1.5.54  
**Autore:** Pasqualino De Marco

## Requisiti

- WordPress 6.0 o superiore
- PHP 8.0 o superiore

## Installazione

1. Scarica [il pacchetto installabile 1.5.54](downloads/archivio-micologico-1.5.54.zip?raw=true).
2. In WordPress apri **Plugin → Aggiungi nuovo → Carica plugin**.
3. Seleziona lo ZIP, installa e attiva **Archivio Micologico**.

Il pacchetto in `downloads/` è una copia identica dello ZIP originale fornito. Per installare usa questo file; lo ZIP generato da GitHub con **Code → Download ZIP** include anche i file del repository.

## Shortcode principali

| Shortcode | Funzione |
| --- | --- |
| `[am_archive]` | Archivio micologico |
| `[am_search_page]` | Ricerca avanzata |
| `[am_random_funghi]` | Schede fungo casuali |
| `[am_submit_form]` | Inserimento schede dal frontend |
| `[am_article_form]` | Inserimento articoli |
| `[am_edit_form]` | Modifica schede |
| `[am_archive_filters]` | Filtri archivio |
